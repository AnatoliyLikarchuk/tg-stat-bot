# Предложения по улучшению бота

## 1. Подтверждение фиксации в группу

**Статус:** На обсуждении

**Описание:**
После успешной записи события в Google Sheets бот отправляет reply-сообщение в группу с подтверждением.

**Сообщение:**
```
✅ Зафіксовано у звіт
```

**Реализация:**
В `bot.py` после успешной записи в таблицу добавить:
```python
await message.reply_text("✅ Зафіксовано у звіт")
```

**Плюсы:**
- Водители видят, что сообщение распознано и записано
- Меньше вопросов "а оно записалось?"
- Прозрачность работы бота

**Минусы:**
- Дополнительные сообщения в чате (может быть шумно)
- Если много событий — много подтверждений

**Альтернативы:**
- Реакция на сообщение вместо reply (менее заметно, но тише)
- Подтверждение только по запросу (команда /check)
