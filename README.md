# Telegram-бот статистики логистики

Бот для автоматического сбора статистики из Telegram-групп: парсинг сообщений о сборке, выезде и доставке маршрутов с сохранением в Google Sheets.

## Возможности

- Автоматический парсинг сообщений в группах (русский/украинский)
- Парсинг подписей к фото (captions) — выезды часто отправляют с накладными
- Распознавание событий: сборка, выезд, завершение маршрута, проблемы
- Извлечение времени, номера маршрута и имени водителя
- Сохранение в Google Sheets (новые события сверху)
- Поддержка нескольких городов — статистика каждого города на отдельном листе
- Реакция 🏆 при успешной записи в отчёт
- Уведомление в чат города когда все маршруты завершены
- Отчёт об активных маршрутах в 19:00 — отдельно по каждому городу
- Кнопки для просмотра статистики с выбором города
- Учёт километража водителей (лист «Пробіг»)
- Управление водителями из личного меню: добавление, перевод в «Звільнені» и восстановление
- Ночная чистка строк статистики старше 90 дней
- Ограничение доступа по белому списку пользователей
- Автодеплой на VPS через GitHub Actions

## Быстрый старт

```bash
# Клонировать репозиторий
git clone https://github.com/AnatoliyLikarchuk/tg-stat-bot.git
cd tg-stat-bot

# Установить зависимости
pip install -r requirements.txt

# Создать конфигурацию
cp .env.example .env
# Заполнить токены в .env

# Запустить бота
python bot.py
```

## Настройка

### 1. Telegram Bot

1. Создай бота через [@BotFather](https://t.me/BotFather)
2. Получи токен и добавь в `.env`

### 2. Google Sheets

1. Создай проект в [Google Cloud Console](https://console.cloud.google.com/)
2. Включи **Google Sheets API** и **Google Drive API**
3. Создай **Service Account** → скачай JSON-ключ
4. Переименуй в `credentials.json` и положи в папку проекта
5. Создай таблицу в Google Sheets
6. Дай доступ (Редактор) email-у из `credentials.json`

### 3. Переменные окружения

```env
TELEGRAM_BOT_TOKEN=123456:ABC-DEF...
GOOGLE_SHEETS_CREDENTIALS_FILE=credentials.json
GOOGLE_SHEETS_SPREADSHEET_NAME=Логистика Статистика
REPORT_CHAT_IDS=                   # ID чатов для автоотчётов через запятую (по чату на город)
ACTIVE_ROUTES_REPORT_TIME=19:00    # время отчёта (по умолчанию 19:00)
RETENTION_DAYS=90                  # чистка строк статистики старше N дней
CLEANUP_TIME=03:00                 # время ночной чистки
TIMEZONE=Europe/Kiev
ALLOWED_USERS=123456789,987654321  # белый список (пусто = все)
```

## Структура таблицы Google Sheets

Статистика каждого города — отдельный лист (вкладка), имя листа = название Telegram-чата. Бот создаёт лист автоматически при первом сообщении из нового чата. Формат каждого листа:

| № | Дата | Время | Событие | Маршрут | Водитель | Исходное сообщение | Группа |
|---|------|-------|---------|---------|----------|-------------------|--------|

- Новые события вставляются **сверху** (строка 2)
- Колонка "№" заполняется автоматически формулой
- Строки старше `RETENTION_DAYS` (90) дней удаляются ночной чисткой

### Лист «Пробіг»

Общий лист (первая вкладка) для учёта километража водителей; водители сгруппированы блоками по городам. Колонка дня вставляется **слева** в блок текущего месяца (свежий день первым). Месячные суммы по каждому водителю считаются формулой `SUMIFS` автоматически. При наступлении нового месяца создаётся новый блок из 3 колонок слева. Формулы новым водителям в уже существующих блоках досоздаёт команда `/backfill`.

В личном меню `👥 Водители` пользователи из `ALLOWED_USERS` могут добавить водителя, переместить его целую строку в нижний раздел `Звільнені` и вернуть обратно в действующий городской блок. Перемещение обратимо: история, норма расхода, формулы и дневные значения не удаляются. Водители из раздела `Звільнені` исключаются из списка, принимающего новый пробег.
