# Telegram-бот статистики логистики

Бот для автоматического сбора статистики из Telegram-групп: парсинг сообщений о сборке, выезде и доставке маршрутов с сохранением в Google Sheets.

## Возможности

- Автоматический парсинг сообщений в группах (русский/украинский)
- Парсинг подписей к фото (captions) — выезды часто отправляют с накладными
- Распознавание событий: сборка, выезд, завершение маршрута, проблемы
- Извлечение времени, номера маршрута и имени водителя
- Сохранение в Google Sheets (новые события сверху)
- Реакция 🏆 при успешной записи в отчёт
- Уведомление в группу когда все маршруты завершены
- Отчёт об активных маршрутах в 19:00 (если есть незакрытые)
- Кнопки для просмотра статистики
- Ограничение доступа по белому списку пользователей
- Автодеплой на VPS через GitHub Actions

## Быстрый старт

```bash
# Клонировать репозиторий
git clone https://github.com/AnatoliyLikarchuk/tg-stat-bot.git
cd tg-stat-bot

# Установить зависимости
pip install -r requirements.txt

# Создать конфигурацию
cp .env.example .env
# Заполнить токены в .env

# Запустить бота
python bot.py
```

## Настройка

### 1. Telegram Bot

1. Создай бота через [@BotFather](https://t.me/BotFather)
2. Получи токен и добавь в `.env`

### 2. Google Sheets

1. Создай проект в [Google Cloud Console](https://console.cloud.google.com/)
2. Включи **Google Sheets API** и **Google Drive API**
3. Создай **Service Account** → скачай JSON-ключ
4. Переименуй в `credentials.json` и положи в папку проекта
5. Создай таблицу в Google Sheets
6. Дай доступ (Редактор) email-у из `credentials.json`

### 3. Переменные окружения

```env
TELEGRAM_BOT_TOKEN=123456:ABC-DEF...
GOOGLE_SHEETS_CREDENTIALS_FILE=credentials.json
GOOGLE_SHEETS_SPREADSHEET_NAME=Логистика Статистика
REPORT_CHAT_ID=                    # ID чата для автоотчётов
ACTIVE_ROUTES_REPORT_TIME=19:00    # время отчёта (по умолчанию 19:00)
TIMEZONE=Europe/Kiev
ALLOWED_USERS=123456789,987654321  # белый список (пусто = все)
```

## Отслеживаемые события

| Событие | Пример сообщения |
|---------|------------------|
| Начало сборки | `6.00 начата сборка маршрут 1 Кияниця` |
| Сборка завершена | `7.40 собран маршрут 1 Кияниця` |
| Выезд | `8.30 выехал маршрут 2 Косич` / `Горбатко выехал` |
| Маршрут завершён | `Маршрут завершив` / `Закінчив` / `Закончил` / `Развез` |
| Проблема | `Точку не доставив` / `Завтра с утра` |
| Пробег | `Косич 120 км` / `Кияниця проехав 95 км` |

## Структура таблицы Google Sheets

| № | Дата | Время | Событие | Маршрут | Водитель | Исходное сообщение | Группа |
|---|------|-------|---------|---------|----------|-------------------|--------|

- Новые события вставляются **сверху** (строка 2)
- При открытии таблицы сразу видны последние события
- Колонка "№" заполняется автоматически формулой

### Лист «Пробіг»

Отдельный лист для учёта километража водителей. Колонка дня вставляется **слева** в блок текущего месяца (свежий день первым). Месячные суммы по каждому водителю считаются формулой `SUMIFS` автоматически. При наступлении нового месяца создаётся новый блок из 3 колонок слева от предыдущего.
