# Telegram-бот статистики логистики

Бот для автоматического сбора статистики из Telegram-групп: парсинг сообщений о сборке, выезде и доставке маршрутов с сохранением в Google Sheets.

## Возможности

- Автоматический парсинг сообщений в группах (русский/украинский)
- Распознавание событий: сборка, выезд, завершение маршрута, проблемы
- Извлечение времени, номера маршрута и имени водителя
- Сохранение в Google Sheets в реальном времени
- Команды для просмотра статистики
- Автоматические ежедневные и еженедельные отчёты

## Быстрый старт

```bash
# Клонировать репозиторий
git clone https://github.com/YOUR_USERNAME/tg-stat-bot.git
cd tg-stat-bot

# Установить зависимости
pip install -r requirements.txt

# Создать конфигурацию
cp .env.example .env
# Заполнить токены в .env

# Запустить бота
python bot.py
```

## Настройка

### 1. Telegram Bot

1. Создай бота через [@BotFather](https://t.me/BotFather)
2. Получи токен и добавь в `.env`

### 2. Google Sheets

1. Создай проект в [Google Cloud Console](https://console.cloud.google.com/)
2. Включи **Google Sheets API** и **Google Drive API**
3. Создай **Service Account** → скачай JSON-ключ
4. Переименуй в `credentials.json` и положи в папку проекта
5. Создай таблицу в Google Sheets
6. Дай доступ (Редактор) email-у из `credentials.json`

### 3. Переменные окружения

```env
TELEGRAM_BOT_TOKEN=123456:ABC-DEF...
GOOGLE_SHEETS_CREDENTIALS_FILE=credentials.json
GOOGLE_SHEETS_SPREADSHEET_NAME=Логистика Статистика
REPORT_CHAT_ID=                    # опционально
TIMEZONE=Europe/Kiev
```

## Команды бота

| Команда | Описание |
|---------|----------|
| `/start` | Приветствие |
| `/stats` | Статистика за сегодня |
| `/stats_week` | Статистика за 7 дней |
| `/routes` | Активные маршруты |
| `/help` | Справка |

## Отслеживаемые события

| Событие | Пример сообщения |
|---------|------------------|
| Начало сборки | `6.00 начата сборка маршрут 1 Кияниця` |
| Сборка завершена | `7.40 собран маршрут 1 Кияниця` |
| Выезд | `8.30 выехал маршрут 2 Косич` |
| Маршрут завершён | `Маршрут завершив` / `Все развез` |
| Проблема | `Точку не доставив` / `Завтра с утра` |
